Return ONLY valid JSON. Use exactly this schema:
{
  "summary": "<Vietnamese operational report, maximum 3 short sentences>",
  "risk_level": "<none|low|medium|high>",
  "events": [
    {"label": "<short Vietnamese operational item>", "count": 0}
  ]
}

Rules for the Vietnamese summary:
- Start with the visible yellow-uniform staff count or an uncertainty statement when it cannot be estimated.
- State only useful operations: staff assisting visitors, processing documents, moving, a visible phone, waiting visitors, an unattended desk, crowding, or a blocked walkway.
- Mention the relevant zone when it is visually identifiable.
- Do NOT describe decorations, banners, architecture, furniture, or general scene details unless they affect safety or operations.

- high: fall, fight, fire/smoke, immediate safety threat, or a clearly blocked exit/walkway.

events:
- Include only operationally significant, visible items.

Return JSON only.
